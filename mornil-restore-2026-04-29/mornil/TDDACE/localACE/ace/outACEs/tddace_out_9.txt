[code-00004] helpful=0 harmful=0 :: def cycpattern_check(a: str, b: str) -> bool:
    """Return True if any left‑rotation of b appears as a substring of a.

    The algorithm iterates over all rotations of b (there are len(b) of them) and
    checks each one against a using the ``in`` operator.  An empty string ``b``
    cannot match a non‑empty substring of ``a`` and therefore returns False.

    if n == 0:
